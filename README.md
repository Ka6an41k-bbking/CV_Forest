# Перенос обучения в задачах определения обособленных препятствий на маршрутах роботизированной лесной техники

**Студент:** Андронов Александр Вячеславович

**Научный руководитель:** Хитров Егор Германович, д.т.н., профессор, доцент факультета технологий искусственного интеллекта

**Организация:** Университет ИТМО

## Описание проекта

Разработать и экспериментально исследовать метод переноса обучения для определения обособленных препятствий на маршрутах движения лесной техники.

Оценка метода проводится на авторском наборе изображений реальных лесных маршрутов. Результаты сравниваются с базовыми моделями, обученными на открытых наборах данных RUGD и FreiburgForest. По итогам исследования определяется модель, показывающая наилучшее качество и обобщающую способность при переносе на новые условия съёмки.

## Цель

Разработать метод генерации структурированных описаний коронарных ангиограмм на основе VLM с внешними медицинскими знаниями, который снижает долю фактических ошибок по сравнению с базовыми VLM. Проверка проводится на разметке датасета ARCADE.

## Направления исследования

1. **Структурированная генерация.** Модель сначала заполняет схему «артерия → сегмент → стеноз → степень → уверенность», а затем схема преобразуется в текст заключения. Так каждое утверждение можно проверить отдельно.
2. **Привязка к изображению.** Каждое утверждение связывается с областью снимка, и его корректность проверяется по маскам ARCADE. Если данных недостаточно, модель явно об этом сообщает.
3. **Способы организации RAG.** Сравниваются текстовый поиск (BM25), плотный поиск, поиск по анатомическим структурам и граф знаний.

## Задачи

1. Провести обзор методов анализа изображений лесной среды, переноса обучения, семантической сегментации и определения препятствий.
2. Исследовать структуру, классы и особенности разметки наборов данных RUGD и FreiburgForest.
3. Определить перечень обособленных препятствий и сформировать единую схему классов.
4. Собрать и аннотировать авторский набор изображений маршрутов роботизированной лесной техники.
5. Подготовить данные для обучения, валидации и тестирования моделей.
6. Обучить базовые модели без дополнительной адаптации к авторским данным.
7. Провести эксперименты по переносу обучения с открытых наборов данных на авторский набор.
8. Сравнить архитектуры CNN и модели на основе трансформеров, включая SegFormer.
9. Оценить качество моделей по метрикам сегментации и определения препятствий.
10. Проанализировать ошибки и влияние особенностей освещения, цветовых каналов и аннотирования сцен.
11. Выбрать модель с лучшими результатами и подготовить прототип системы определения препятствий.
